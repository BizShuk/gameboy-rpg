# 術語表 (Terminology)

單一定義來源：領域名詞、狀態值與縮寫以本表為準。

| 術語 | 定義 |
| ---- | ---- |
| `safe zone` (安全區) | 怪物禁入、玩家不受傷且緩慢回血的 tile 矩形；目前有綠泉鎮與地下層營地兩處 |
| `營地` (camp) | 地下層階梯周圍的安全區 (雙營火)；探索補給點 |
| `Progress` | 可存檔的玩家進度：quest/裝備/金幣/背包 (不含座標)，key 為玩家名稱 |
| `Store` | 進度儲存體介面；`MemStore` 記憶體、`store.File` JSON 檔 |
| `wild area` (野區) | 安全區以外全部區域；怪物生成與戰鬥發生地 |
| `tick` | 伺服器模擬步；`TickRate = 20` (每 50ms 一步)，冷卻/重生皆以 tick 計 |
| `unit` (人物單位) | 距離基準：1 unit = 一個人物寬 = 1 tile；所有 gameplay 數值以此表達, px 僅渲染層 |
| `snapshot` (快照) | 每 tick 廣播的全量世界狀態 `st{p,m,e}` |
| `event` | 快照附帶的一次性視覺事件：`sl`/`hit`/`die`/`gold`/`heal` |
| `aggro` (索敵) | 怪物偵測半徑；玩家進入且不在安全區即被追擊 |
| `leash` (脫戰距離) | 怪物離家 (home) 上限；超出即放棄目標返家 |
| `home` | 怪物出生點；wander 與 respawn 的錨點 |
| `respawn` (重生) | 玩家死後 3s 回城鎮出生點；怪物死後 10s 回 home |
| `kind` | 怪物種類 id：`slime` / `beetle` / `wolf` |
| `counter` (櫃檯) | tile `C` 武器店 / `A` 道具店；玩家靠近 44px 內才能交易 |
| `store` | 商店歸屬：`weapon` (武器) / `gear` (防具+消耗品)；買錯櫃檯會被拒 |
| `buff` | 消耗品限時效果：`bs` 加速 / `ba` 加攻，單位為剩餘 tick |
| 武器參數 | `CD` 攻擊冷卻 ticks、`Reach` 觸點距離 px、`Radius` 判定半徑 px |
| `edge trigger` | 攻擊訊息模式：按一下送一次 `atk`，非持續狀態 |
| `月光水晶` | 世界觀核心：水井中維持結界的水晶；安全區的敘事來源 |
| `月蝕化` | 怪物暴走的劇情設定；主線起因 |
| `北之森` / `月光神殿` | 北方劇情區域：暗色森林與最終 Boss 所在石殿 |
| `stage` (劇情階段) | 玩家主線進度 `Quest` 0-8；定義於 `story.go` Stages |
| `素材` (material) | 擊殺掉落的劇情物品：`凝膠`/`甲殼`/`狼牙`，存於 Inv |
| `鍛造` (craft) | 對話動作以素材+金幣直接換裝備；非商店交易 |
| `共鬥判定` | Boss 死亡時擊殺者與 320px 內同階段玩家一起過關 |
| `outbox` | World 對特定玩家的訊息佇列，由 Hub drain 轉發 |
| `地下層` (Abyss) | 第二章洞窟區 (rows 64-87)；黑暗光照、熔岩、隕鐵礦、深淵之門 |
| `月之裏側` (Void) | 第三章虛空區 (rows 88+)；浮島、星光橋、極光、核心祭壇 |
| `Portal` | 傳送點：踩上即移動；`MinQuest` 為劇情閘門 (深淵之門) |
| `階梯傳送` | 踩神殿 `>` 下地下層、踩 `<` 回神殿；落點錯開一格防彈跳 |
| `狂暴` (rage) | Boss 血量低於 `enrageAtPct` 後變色、加速、技能冷卻減半 |
| `震地波` (slam) | 暗月魔像技能：警告圈蓄力 1s → 半徑 3 人單位全體傷害 |
| tile 走得過 | `.` 草 `,` 花 `g` 草叢 `P` 路 `p` 石板廣場 `f` 農田 `b` 木橋 `_` 森林暗地 `k` 森林暗草 `q` 神殿地板 `d` 洞窟地 `^` 營火 `<`/`>` 階梯 `n` 星石地板 `:` 星光橋 `@` 傳送門 |
| tile 擋路 | `T` 樹 `W` 水 `y` 蓮葉水面 `F` 籬 `H` 牆 `R`/`U`/`V` 紅藍綠頂 `D` 門 `C`/`A` 櫃檯 `S` 告示 `O` 水井 `L` 路燈 `B` 灌木 `x` 木箱 `t` 樹樁 `r` 岩石 `Z` 神殿石牆 `M` 水晶祭壇 `c` 洞窟壁 `l` 熔岩 `o` 火把 `m` 隕鐵礦 `G` 深淵之門 `v` 虛空 `*` 星辰水晶 `E` 核心祭壇 |
