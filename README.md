# game1 — PokeTown Online

Pokemon Red/Blue 復古風格的`多人連線動作 RPG demo`，含`三章完整主線劇情`
《綠泉鎮與月光水晶》(見 `docs/story.md`)。城內是安全區 (safe zone)，
野外與地底/虛空各層有怪物即時追擊；接任務、採素材、鍛造神兵、
討伐五隻 Boss 直到傳說完結。

## 快速開始 (Quick Start)

```bash
./run.sh                      # 建目錄 + build + 啟動 (pm2 也用這支)
open http://localhost:8470    # 多開分頁或區網其他裝置連入即為多人
```

設定優先序：`-addr`/`-save` flag > `APP_ADDR`/`APP_SAVE` 環境變數 >
`~/.config/game1/game1.yaml` (範例見 `config/example/`) > 內建預設。
常駐執行：`pm2 apply && pm2 start game1`。

分享連結可帶名字直接入場：`http://<host>:8470/?name=Ash`。

`進度會自動保存`：用同一個名字重新連線即續玩 (劇情階段、裝備、金幣、背包)。
存檔位於 `~/.config/game1/data/players.json`，`-save ""` 可停用持久化。

## 操作 (Controls)

| 按鍵 | 動作 |
| ---- | ---- |
| `WASD` / 方向鍵 | 移動 (free movement, 非格子鎖定) |
| `J` / `Space` | 攻擊 (面向前方揮擊, 參數依武器) |
| `E` | 與 NPC 對話 / 開關商店 (武器店/道具店/營地補給站) |
| `1`-`4` / `Q` | 使用消耗品 (Potion / Hi-Potion / Haste / Power) |
| `P` | 切換野區決鬥模式 (雙方都開才會互相傷害) |
| `M` | 靜音切換 (右上角亦有音量滑桿) |
| 觸控 | 行動裝置自動顯示虛擬搖桿與攻擊/互動/藥水鍵 |

## 玩法循環 (Gameplay Loop)

1. 出生於城鎮廣場，開場劇情引導找`村長羅文` (頭上有金色 `!`) 接主線。
2. 依任務鏈行動：採集素材 (`凝膠`/`甲殼`/`狼牙` 擊殺自動掉落) → 找
   `鐵匠布拉姆`鍛造劇情裝備 → 北上`北之森` → 討伐`月蝕狼王`與神殿的
   `暗影史萊姆王` → 水晶復明拿 `Moon Blade`，全鎮煙火 (八幕詳見 `docs/story.md`)。
3. 即時戰鬥：怪物主動索敵、追擊、近戰；Boss 有衝刺/召喚技能；
   玩家揮擊範圍/攻速依武器不同。
4. 金幣採購：`武器店` (紅頂, 7 把武器) 與`道具店` (藍頂, 5 件防具 + 4 種
   消耗品含 buff 藥水)；劇情裝備僅能鍛造/獎勵取得。
5. 倒地後 3 秒於城鎮重生；小怪 10 秒重生, Boss 60-75 秒。

## 地圖區域 (Areas)

`綠泉鎮` (安全區) → 四方野區 (西/南 Slime、東 Beetle、北 Wolf) →
`北之森` (狼群與獸穴) → `月光神殿` (石殿與發光祭壇) →
`神殿地下層` (黑暗洞窟、熔岩、隕鐵礦、營地補給點、深淵之門) →
`月之裏側` (虛空浮島、星光橋、極光、核心祭壇)。

三層之間以`階梯`與`傳送門`相連 (深淵之門需劇情進度才開啟)。

## 多人連線 (Multiplayer)

WebSocket 即時同步：所有玩家共享同一世界，互相可見走位、揮擊、擊殺與裝備。
Server 為唯一權威 (server-authoritative)，client 僅上報輸入與渲染插值。

技術結構與協定見 `CLAUDE.md`；領域名詞見 `docs/terminology.md`。
